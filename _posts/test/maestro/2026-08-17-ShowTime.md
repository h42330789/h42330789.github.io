1、编译ShowTime.framework
1.1、下载[ShowTime](https://github.com/KaneCheshire/ShowTime), 并打开`ShowTimeExample`项目
![image](/assets/img/test/showtime/ShowTime1.png)

1.2 在xcode里创建一个一个Target: 
步骤1：
`+` -> `iOS` -> 搜索`framework` -> 选中 `Frameworks & Library` -> `Framework` -> 点击`Continue`
![image](/assets/img/test/showtime/ShowTime2.png)

步骤2：
`Product Name`里输入`ShowTime`
`Organization Identifier`里随便输入
点击`Finish`
![image](/assets/img/test/showtime/ShowTime3.png)

步骤3：
在`Build Settings`里, 将`Defines Module`、`BUILD_LIBRARY_FOR_DISTRIBUTION`两个都设置成`No`
![image](/assets/img/test/showtime/ShowTime4.png)
![image](/assets/img/test/showtime/ShowTime5.png)

步骤4：
将Scheme文件夹`ShowTime`里的`ShowTime.h`删除
![image](/assets/img/test/showtime/ShowTime6.png)
将源文件`ShowTime.swift`加入Scheme文件夹`ShowTime`
![image](/assets/img/test/showtime/ShowTime7.png)

步骤5，编译出framework：
使用xcode自动导出的效果
`scheme`选择`ShowTime` -> target选择
![image](/assets/img/test/showtime/ShowTime8.png)

步骤6：
`Xcode`->`Product`->`Show Build Folder in Finder` 
在打开的文件夹里：`Products`-> `Debug-iphonesimulator`

使用脚本导出的效果方式

```
# 进入项目位置
cd /Users/xxx/xx/xx/ExampleApp
# 检查scheme列表
# xcodebuild -list
xcodebuild \
  -scheme ShowTime \
  -destination 'generic/platform=iOS Simulator' \
  -configuration Debug \
  BUILD_LIBRARY_FOR_DISTRIBUTION=NO \
  build
```

---

将得到的`ShowTime.framework`加入到运行汇总的模拟器

```
export SIMCTL_CHILD_DYLD_INSERT_LIBRARIES=path/to/ShowTime.framework/ShowTime &&
xcrun simctl launch booted org.wikimedia.wikipedia
```

或者直接注入到启动模拟器的启动桌面，就可以所有操作点击都能看到

```
# 注入动态库
xcrun simctl spawn booted launchctl setenv DYLD_INSERT_LIBRARIES /path/to/ShowTime.framework/ShowTime
# 重启桌面程序
xcrun simctl spawn booted launchctl stop com.apple.SpringBoard

# 两条命令合并的的命令，我的本地是把库放在了桌面
xcrun simctl spawn booted launchctl setenv DYLD_INSERT_LIBRARIES ~/Desktop/ShowTime/ShowTime.framework/ShowTime && \
xcrun simctl spawn booted launchctl stop com.apple.SpringBoard
```

解除该库的影响

```
# 将环境去掉动态加载的库
xcrun simctl spawn booted launchctl unsetenv DYLD_INSERT_LIBRARIES
# 重启桌面
xcrun simctl spawn booted launchctl stop com.apple.SpringBoard
# 合并的命令
xcrun simctl spawn booted launchctl unsetenv DYLD_INSERT_LIBRARIES ; \
xcrun simctl spawn booted launchctl stop com.apple.SpringBoard
```

如果重启模拟器，就会自动失效
